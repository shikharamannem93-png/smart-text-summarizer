# 🧠 Smart Text Summarizer

A simple yet powerful **Generative AI** app that summarizes any text or document using **OpenAI GPT-4o-mini** — built with **Streamlit** and deployed on **Hugging Face Spaces**.

---

## 🧩 Features
- ✍️ Paste any text (article, report, email)
- ⚡ Generate concise, clear summaries instantly
- 🌈 Streamlit-based clean UI
- 🔒 Secure: API key managed through Hugging Face secrets
- 🧠 Uses `gpt-4o-mini` for fast, cost-efficient summarization
